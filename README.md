# ☕ Soluções Beecrowd em Java

Repositório dedicado ao armazenamento das minhas resoluções de problemas da plataforma **[Beecrowd](https://www.beecrowd.com.br/)**, desenvolvidas em **Java** com foco em lógica de programação, estruturas de dados e otimização de algoritmos.

---

## 📁 Estrutura do Repositório

As soluções estão organizadas por categorias da plataforma para facilitar a consulta:

```text
📦 beecrowd-java
 ┣ 📂 iniciante
 ┣ 📂 ad-hoc
 ┣ 📂 strings
 ┣ 📂 estruturas
 ┗ 📂 matematica
```

---

## 🚀 Padrão dos Arquivos

* **Nomenclatura:** Os arquivos seguem o padrão `Bee<ID>.java` (ex: `Bee1001.java`), correspondendo ao número oficial do problema.
* **Classe Principal:** Todas as soluções utilizam `public class Main`, conforme exigido pelo juiz online do Beecrowd.
* **Status:** Apenas códigos com status **Accepted** são enviados para este repositório.

---

## 🛠️ Tecnologias

* **Linguagem:** Java (JDK 17+)
* **Plataforma:** Beecrowd Online Judge
